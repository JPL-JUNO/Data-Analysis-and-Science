## 数据说明

从 [UCI](https://archive.ics.uci.edu/dataset/27/credit+approval) 机器学习存储库下载、准备和存储信用审批数据集的指南，该存储库获得 [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode) 许可。

在 [credit-approval-dataset.py](https://github.com/JPL-JUNO/Data-Analysis-and-Science/blob/pyfec/Python-Feature-Engineering-Cookbook/DATA/credit-approval-dataset.py) 对原始数据做了一些调整。

我们还将使用位于 Facebook 的 Prophet GitHub 存储库中的 [air passengers](https://github.com/facebook/prophet/blob/main/examples/example_air_passengers.csv)，根据 [MIT](https://github.com/facebook/prophet/blob/main/LICENSE) 许可证授权。
